# Publish Bachpan TV on GitHub Pages — 2 minutes, no coding

Do this on your Windows PC.

## Step 1 — Create the repo (30 seconds)
1. Go to https://github.com/new (sign in as **ankitgarg43**)
2. Repository name: `bachpan-tv`
3. Keep it **Public**, do NOT tick any boxes (no README, no .gitignore)
4. Click **Create repository**

## Step 2 — Upload the files (1 minute)
1. On the new repo page, click **uploading an existing file**
2. Drag ALL files from the unzipped `bachpan-tv` folder into the page:
   `index.html`, `favicon.svg`, `manifest.webmanifest`, `robots.txt`, `sitemap.xml`, `README.md`, `.nojekyll`
   (skip this PUSH file, or include it — harmless either way)
3. Click **Commit changes**

## Step 3 — Turn on Pages (30 seconds)
1. In the repo: **Settings → Pages** (left sidebar)
2. Under "Build and deployment": Branch = **main**, folder = **/ (root)**, click **Save**

## Step 4 — Watch TV (after ~1–2 minutes)
Open: **https://ankitgarg43.github.io/bachpan-tv/**

Share that link with anyone — no login, they just press Power.

---
### If the link shows 404
Wait 2 more minutes and refresh. Pages takes a little time the first time.
Check Settings → Pages — it should say "Your site is live at https://ankitgarg43.github.io/bachpan-tv/".
